# City Life Score Dashboard

City Life Score Dashboard is a premium city comparison experience that blends real-time weather, air quality, country stats, and developer activity into a single livability score.

## Prerequisites

- Node.js 18+
- npm

## How to run

1. `git clone <your-repo-url>`
2. `npm install`
3. `cp .env.example .env.local`
4. Add your OpenWeatherMap API key in `.env.local`
5. `npm run dev`

Open http://localhost:3000

## Getting a free OpenWeatherMap key

Create a free account at https://openweathermap.org/api and generate an API key (free tier includes 1,000 calls/day).

## Deployment

`vercel deploy`
